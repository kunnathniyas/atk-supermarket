Firestore Rules Setup Needed

Firebase requires read/write permissions for your database. In your Firebase console, go to Firestore Database → Rules tab and paste this rule: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Click Publish in Firebase rules. Once published, click continue below.
